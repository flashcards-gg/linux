# Flashcards.gg for Linux — release assets

Pre-built Linux bundles of [Flashcards.gg](https://flashcards.gg), the AI
flashcards app (spaced repetition, works offline). The application is closed
source; this repository only publishes the release archives that the
[Flathub package](https://flathub.org/apps/gg.flashcards.Flashcards) and the
[Snap Store package](https://snapcraft.io/flashcards) are built from.

- **Install:** `flatpak install flathub gg.flashcards.Flashcards` or
  `snap install flashcards`
- **Assets per release:** `flashcards-<version>-linux-x64.tar.gz` and
  `flashcards-<version>-linux-arm64.tar.gz` — the Flutter bundle
  (`flashcards`, `lib/`, `data/`) plus hicolor icons.
- **Issues:** bugs in the Linux builds go to the issue tracker here;
  everything else to support@flashcards.gg.
- **Website / privacy policy:** https://flashcards.gg · https://flashcards.gg/policy.html
